# 2D игра на Python (с использованием Pygame)
Это простенькая игра с видом сверху, где игрок управляет синим автомобилем и должен добраться до синей клетки парковки для прохождения уровня.

![](https://github.com/TOXYGENCY/2d_pygame/blob/main/assets/png/game.png)

# Особенности
- Стилизованная пиксельная графика
- Спрайты формата `.png` размером `100x100px` для каждой сущности/клетки в игре (при желании можно заменить на свои)
- Счетчик "шагов", сделанных на уровне
- Возможность создать свои уровни и полноценно в них играть
- `4` типа клеток (Свободная клетка, Стена, Сад, Парковка), `3` передвигающиеся сущности (Игрок, Такси, Враг) и `1` коллекционный предмет (Монетка).
- Запуск без кода через `.bat` файлы
- Стилизованное управление, более похожее на управление авто *(да, даже в игре с перемещением по клеткам)*

# Запуск
*⚠ Для запуска необходимо иметь язык программирования Python, установленным на устройстве.*

**✅ Вариант 1**: запустить файл `start_game.bat` чтобы открыть игру на стандартном уровне

**✅ Вариант 2**: запустить файл `choose_level_and_start.bat` и написать в появившйся командной строке название уровня без расширения файла *(напр. если файл уровня называется `level3.txt`, то надо написать `level3`)*

**✅ Вариант 3**: через командную строку открыть корневую папку с игрой (там, где лежит файл `main.py`) и выполнить команду:
```
python main.py
```
или дополнительно указать имя файла с желаемым уровнем:
```
python main.py level3
```

# Управление
- Управление с клавиатуры: `W A S D` или `↑ ↓ ← →`
- Перезапуск уровня: `R`
- Выход из игры: `Esc`

**⚠ Внимание!** Нажимать на клавиши управления нужно немного дольше, чем обычно. Это фишка игры, связанная с стилизованным управлением авто.

# Как создать свой уровень?
1. Переходим в папку `levels` в корне игры
2. Создаем новый текстовый файл (формат `.txt` обязателен)
3. Теперь можно писать символы на латинском языке, чтобы указывать сущность клеток. В ширину 9 символов (клеток), в высоту 7 *(игра имеет размер `900x700px`, а каждая клетка имеет размеры `100x100px`)*
Для удобства, можно вставить следующий шаблон для редактирования, который уже имеет правильные размеры и содержит стены на краях уровня и игрока посередине:
```
111111111
100000001
100000001
1000P0001
100000001
100000001
111111111
```
4. Измените уровень по своему желанию, опираясь на следующие возможные символы:

| Символ (латиница) | Спрайт | Описание |
|---------|-------------|--------|
| `0` | ![](https://github.com/TOXYGENCY/2d_pygame/blob/main/assets/png/tiles/road_plain.png) | **Свободная клетка.** Игроки/сущности могут спокойно перемещаться по этой клетке. |
| `1` | ![](https://github.com/TOXYGENCY/2d_pygame/blob/main/assets/png/tiles/wall_plain.png) | **Стена.** Игроки/сущности не могут ее занимать. При перемещени на эту клетку, игра завершается провалом. При каждом перезапуске уровня спрайт поворачивается на случайный угол. |
| `2` | ![](https://github.com/TOXYGENCY/2d_pygame/blob/main/assets/png/props/trees.png) | **Мини-сад с деревьями.** То же самое, что и стена, но с другим спрайтом. |.
| `E` | ![](https://github.com/TOXYGENCY/2d_pygame/blob/main/assets/png/tiles/exit_plain.png) | **Парковка.** Клетка с целью уровня, до которой нужно добраться игроку. При перемещени на эту клетку, игра завершается победой. Сущности не могут ее занимать. ***На уровне обязательно должна быть хотя бы одна парковка.*** |
| `C` | ![](https://github.com/TOXYGENCY/2d_pygame/blob/main/assets/png/collectables/coin.png) | **Монетка.** Клетка с дополнительный бонусом, который можно подобрать, заняв эту клетку. Сущности не могут ее занимать. ***На уровне обязательно должна быть хотя бы одна монетка.*** |
| `P` | ![](https://github.com/TOXYGENCY/2d_pygame/blob/main/assets/png/cars/player/blue_coupe_r.png) | **Старт игрока.** Стартовая клетка для игрока, на которой будет появляться синее авто, которым можно управлять. ***На уровне обязательно должен быть игрок и только один.*** |
| `N` | ![](https://github.com/TOXYGENCY/2d_pygame/blob/main/assets/png/cars/npc/npc_r.png) | **Старт такси (NPC).** Стартовая клетка для такси, которые будут свободно перемещаться по уровню. При перемещени на клетку, уже занятую такси, игра завершается провалом. Такси ***не может*** перейти на клетку с игроком. |
| `X` | ![](https://github.com/TOXYGENCY/2d_pygame/blob/main/assets/png/cars/enemy/red_muscle_r.png) | **Старт врага (NPC).** Стартовая клетка для врага, которые будут свободно перемещаться по уровню. При перемещени на клетку, уже занятую врагом, игра завершается провалом. Враг ***может*** перейти на клетку с игроком и завершить игру провалом. |



5. Чтобы запустить уровень, используйте **✅ Вариант 2** запуска игры через файл `choose_level_and_start.bat` и введине название файла своего уровня
6. Играйте!

### Для примера, уровень со скриншота выше выглядит вот так:
```
111111111
00000000C
0N1100120
2XC110000
100111001
1000110P1
1200E1N11
```
